# Daily English Study

TOEIC vocabulary study dashboard and Windows desktop app.

## Included

- TOEIC dashboard and weather/calendar UI
- Randomized TOEIC quiz with configurable question count
- 1,000-item candidate vocabulary source
- WebView2 WinForms app source
- Inno Setup script

The latest Windows installer is built locally as `Daily_Study_App_Setup.exe`.
